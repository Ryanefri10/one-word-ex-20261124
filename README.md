One word my ex would use to describe me: **Project**. She took me on as a project, convinced she could fix me — and I stayed exactly as I was. Funny at once, painfully honest, and instantly relatable: everyone has either been the project or dated one.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR` for local runs).
